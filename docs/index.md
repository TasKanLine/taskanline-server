## Что такое TasKanLine

TasKanLine — асинхронный REST API-сервер для управления задачами в стиле Kanban. Построен на FastAPI с полностью асинхронным стеком: asyncpg для работы с PostgreSQL и SQLAlchemy 2.0 в роли ORM.

Система поддерживает иерархическую модель данных:

```
Пользователь
  └── Проект (Project)
        └── Доска (Board)
              └── Колонка (Column)
                    └── Задача (Task)
```

## Ключевые возможности

- JWT-аутентификация через cookie и `Authorization` заголовок
- Хеширование паролей через Argon2
- Полный CRUD для проектов, досок, колонок и задач
- Перемещение задач между колонками с управлением позицией
- Каскадное удаление: удаление проекта удаляет все дочерние сущности
- Автоматическая документация API: `/docs` (Swagger), `/redoc`

## Быстрый старт

```bash
# 1. Создать .env из шаблона и заполнить реквизиты PostgreSQL
cp .env.example .env

# 2. Установить зависимости и запустить (hot reload)
make dev

# 3. Применить миграции
uv run alembic upgrade head
```

После запуска: `http://localhost:8000/docs`
